## ❓ FAQ

**Q: Will DLSS 5 work on my RTX 2060?**  
A: Yes, via Feeder route. Performance will be lower than on RTX 40/50 cards.

**Q: Does it work with AMD GPUs?**  
A: Yes — RDNA 3/4 supported via Feeder. OptiScaler is experimental on AMD.

**Q: Can I use it in online games?**  
A: **No.** Anti-cheat may ban you. Single-player only.

**Q: What is Multipass?**  
A: It runs the neural pass up to 10 times per frame for higher quality at a performance cost.

**Q: Do I need ReShade for Feeder?**  
A: Yes — Feeder uses the ReShade depth buffer to feed data to DLSS.

**Q: Is there a classic ZIP download?**  
A: Yes — check the Releases section. Password is `2026`.

**Q: How do I uninstall?**  
A: Use "Restore originals" in the app. Uninstalling the app alone does not touch game folders.

**Q: Does it work with Xbox Game Pass?**  
A: Yes — modern Xbox Game Pass folders are auto-detected.

**Q: Where are config files stored?**  
A: `%LOCALAPPDATA%\DLSS5Manager\`

**Q: What is DLSS5-Swapper?**  
A: It's the core utility that installs, tunes, and restores DLSS 5. DLSS5-Manager bundles it with additional features.

**Q: What is DLSS5-Feeder?**  
A: It adds synthetic DLAA to games without native DLSS support.

**Q: What is OptiScaler?**  
A: An alternative injection route for eligible games.

**Q: What is RenoDX?**  
A: A DirectX modding framework built around ReShade's add-on system.
